# Thames repair candidate — v24

Expanded the bundled Thames layer from 23 to 42 polygons using the original 468-feature Overpass export. Added 19 unlabelled river-water polygons touching the earlier selected river geometry. Explicitly excluded named tributaries.

**Not a certified continuous Thames.** Union still has 1 disconnected polygon components. The source export does not demonstrate complete Thames coverage and some polygons may be mapped as separate segments. No fabricated bridging geometry was added.

This is an incremental river repair, not a verified full-Thames release. Use index.html, railway-data.js and the accompanying GeoJSON files together. OSM attribution: © OpenStreetMap contributors, ODbL.
